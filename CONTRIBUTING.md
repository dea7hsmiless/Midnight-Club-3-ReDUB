# Contributing

ReDUB is a Windows community edition based on the original Xbox static recompilation work. Contributions that improve the Windows launcher, setup flow, OpenGL/Vulkan rendering, input, or documentation are welcome.

## Build

Start with [BUILDING-WINDOWS.md](BUILDING-WINDOWS.md). Test changes with legally obtained game data that you are authorized to use. Do not add disc images, extracted game files, save data, credentials, NVIDIA SDK/runtime files, or third-party texture packs to commits.

## Pull requests

Keep changes focused and describe the user-visible effect, affected renderer or platform, and the verification performed. Include reproduction steps for bug fixes. Do not claim broad stability from a short local test.

## Upstream projects

ReDUB builds on [mcdub3-nx](https://github.com/laureladastra/mcdub3-nx) and the [xboxrecomp toolkit](https://github.com/sp00nznet/xboxrecomp). Changes that also apply upstream should be proposed to the relevant project separately.
