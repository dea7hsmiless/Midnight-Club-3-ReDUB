# ReDUB release notes

## 0.1.0 — Windows Edition — 2026-11-13

- Portable setup launcher with original Xbox Remix import, setup verification, repair, local builds, shortcuts, and launcher bypass recovery.
- Native Port Options with graphics presets, scaling, FXAA profiles, filtering, sharpening, gamma, brightness, VSync, FPS display, controller rumble, and Windows media integration.
- OpenGL and Vulkan renderers, with optional NVIDIA DLSS Super Resolution in Quality, Balanced, and Performance modes. DLSS jitter is off by default; Vulkan/DLSS remains experimental.
- Xbox controller support, configurable rumble, experimental raw SDL wheel input, and PC music controls through Windows media sessions.
- Renderer and presentation fixes for Career loading, minimap masking, fullscreen/resolution handling, and Vulkan effects parity.

See [README.md](README.md) for system requirements, game-file requirements, setup, limitations, and legal guidance. See [BUILDING-WINDOWS.md](BUILDING-WINDOWS.md) to build from source.
